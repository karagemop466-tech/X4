VERIFICATION STANDARD

How to trust this page

NO HALLUCINATIONS
Three rules, applied row by row

1) Every factual table row carries a source link to the page it came from. 2) If a value cannot be confirmed from an official source it is left blank and flagged on the Flagged for review page — never inferred, never filled in. 3) Every computed number (home edge, correlations, baseline lines) is reproduced by tools/compute_stats.py from committed CSVs whose inputs are the linked official fetches.

Not betting advice. Baseline lines and market comparisons are research artifacts for validating a process. No picks, no edges claimed, no performance claimed. Strategy gates have not been run; the leaderboard is a design, not a result.
