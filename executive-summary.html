VERIFIED SNAPSHOT
Season state
2026 NFL regular season, Week 10 in progress (TNF Nov 12: Commanders 24, Giants 21 final; Sunday Nov 15 slate pending). Source: nfl.com/scores ↗
Standings captured
All 32 teams, W-L-T / PF / PA / net, including the Week-10 TNF result. Source: nfl.com/standings ↗ — transcription self-checked (ΣPF = ΣPA = 6,291; wins = losses = 136).
Results captured
57 final scores from Weeks 6–9 (3 neutral-site games identified and excluded from home-edge math). Each row links its official game page. See Verified data.
Lines originated
A transparent baseline produced spreads and totals for all 13 Week-11 games, compared against the market snapshot (DraftKings odds as published by ESPN). Model is v0 — no injury, rest or QB adjustments yet. See Line lab.
Correlation values
Four correlations computed from official data with 95% CIs — including margin-vs-total r = −0.32 (parlay-relevant) and point-differential-vs-win% r = 0.87 (strength-signal validation). See Correlations.
Home edge (measured)
+0.1 pts mean home margin, n = 54, 95% CI [−3.6, +3.7] — this 4-week window shows no reliable home edge; the model therefore carries wide uncertainty. See Correlations.
Injury tracking
Official Week-10 injury report sampled (practice + game statuses, 22 rows published with player-level links). Depth is now measured: 1,558 depth positions transcribed from the clubs' own official charts (31 of 32 clubs publish an ordered chart; Houston publishes only an image and is flagged), joined by name to the official report. Replacement starts are measured for 2 of 7 starter absences; the rest are named but have not yet started. See Depth & deficiency and Availability.
Validation gates
8 gates defined (data integrity → shadow period). Five are blocked on a named missing input and three are built and measured — nothing is scored as a result, so no strategy performance is claimed anywhere on this site. The demotion gate (live → paper) is published with its rules and a run of the graded rows. See Integrity & programme and Gates.
Leaderboard
Competition designed for three divisions (singles / parlays / prop combos) with anti-luck scoring; reward pool amount is an owner decision (blank + flagged). See Leaderboard.
Open flags
12 unverified items (left blank) + 12 repo irregularities (evidence-linked). None block the merge; all published on Flagged for review.

The one-line state of the project. The data layer is now verified and can settle a bet; the market layer is captured but has never been traded; the strategy layer is paper-only with nine settled bets. Every recommendation on the site therefore reduces to the same two cheap actions: write the price before the kick-off, and settle the 136 games already in the feed. Until those land, no money-related claim in this repository is supportable - and the site says so on the page rather than in a footnote.
