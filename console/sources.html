Source Register

Every source used anywhere on this site, tiered by how much weight it can carry. All were retrieved during this session, on 2026-11-14.

Tiering rules

primary
Official
The league (nfl.com, operations.nfl.com), official club sites, regulators, government bodies, standards bodies, or this repository's own artifacts. Sufficient on its own to mark a value verified.
academic
Peer-reviewed
Peer-reviewed or university-published work, cited with a DOI or institutional URL. Sufficient for a methodological claim, not for a league fact.
secondary
Not sufficient alone
Media, aggregators and analytics blogs. Used only for context, methodology discussion, or as evidence of a cross-source conflict. Never used on its own to mark a value verified.
Two negative findings are recorded as sources. A source row that documents the absence of data is as important as one that documents its presence — see NFL_DEPTH_CHART_404 (NFL.com has no depth charts) and AGG_STANDINGS_CONFLICT (an aggregator contradicts the official standings).

The register

Verification policy, restated

  1. A value is verified only if it was read off a primary source during this session and that source's URL is recorded on the row.
  2. Values shown as design are this project's own engineering proposals — thresholds, schemas, workflows. They are not facts and are labelled as proposals everywhere they appear.
  3. Values shown as secondary rest on a media or aggregator source and should be re-checked against a primary one before being relied on.
  4. Values shown as unverified are unknown. They are left blank and appear on the Flagged for Review page.
  5. Nothing is inferred, interpolated, modelled or filled in. Unknown means blank.

What is deliberately absent from this register

There is no row for an odds provider, because none was evaluated. There is no row for a depth-data provider, for the same reason. Those two absences are the project's two largest blockers (F-02, F-03), and naming a provider without reading its own documentation would violate the policy above.
