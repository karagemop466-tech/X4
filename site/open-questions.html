Why this page is generated

A register of unknowns that is itself out of date is worse than none

A previous session found the site a week stale because a completed slate had not been ingested (F-58), and a later read found stale counts surviving in prose the gate does not check (F-66). This register was therefore built as a generator rather than a document: python3 tools/open_questions.py --check fails the publication gate when any count it quotes stops matching the committed data. When a gate clears, this page changes by itself, and if it does not, the build breaks.
