One row per club

The roster sweep, made visible: which charts are represented, and where a shared slot is still not expressed.

31 clubs publish an ordered chart and every one of them is transcribed below. The transcription can now put two men in one cell: a club that prints a co-starter is stored as a shared cell, not as a starter and a backup. The shared column shows how many cells in each club's sheet hold more than one player — it is 1 across all 31 clubs. The special teams column is zero everywhere, for a different reason: those rows have never been transcribed for any club.

Two kinds of row appear here and they mean different things. cell-checked means the live club page was read and compared name by name. dataset only means the row reports what the committed file holds — it is not a claim that the live page still matches it, and clubs edit their charts during the week.

What a correct transcript needs

Four changes, each checkable — and where each one stands

Same depth, shared cell
PASS Both players in a printed first cell must carry the same depth number. Test: the Seattle WR row must read Kupp 1, Shaheed 1, Charles 2. It now reads 1 1 2.
Empty cells kept
PASS A club that names no third player must be distinguishable from one we did not record. Test: Washington's third WR row has an explicitly empty second cell. It now has 1 printed empty cell in the dataset.
Special teams included
OPEN P, K, H, LS, KR and PR are chart rows. Test: every club row above shows a non-zero special-teams count that matches its live page. The dataset holds 0 special-teams rows, because those rows have never been transcribed.
Versioned against roster moves
PASS A chart is only true until the next transaction. Test: each row carries the club's own printed date where it has one, and the capture is superseded when the transaction log shows a move. 251 rows carry a club-printed date; the Washington chart was re-read on 2026-11-19 and had changed since 2026-11-14, which is the case the date column has to answer.
