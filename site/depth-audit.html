One row per club

The roster sweep, made visible: which charts are represented, and where a shared slot cannot be expressed.

31 clubs publish an ordered chart and every one of them is transcribed below. What the transcription cannot yet do is put two men in one cell: a club that prints a co-starter gets a starter and a backup in the dataset instead. The shared column shows how many cells in each club's sheet hold more than one player — it is 0 across all 31 clubs, which is the defect, stated as a number per club rather than as a disclaimer. The special teams column is zero everywhere for the same reason: those rows were never transcribed.

Two kinds of row appear here and they mean different things. cell-checked means the live club page was read this session and compared name by name. dataset only means the row reports what the committed file holds — it is not a claim that the live page still matches it, and clubs edit their charts during the week.

A shared cell of 0 is not a clean sheet. It is the signature of the collapse: no club in this dataset has even one cell with two players, while live pages read this session do.

What a correct transcript needs

Four changes, each checkable

Same depth, shared cell
Both players in a printed first cell must carry the same depth number. Test: the Seattle WR row must read Kupp 1, Shaheed 1, Charles 2.
Empty cells kept
A club that names no third player must be distinguishable from one we did not record. Test: Washington's third WR row has an explicitly empty second cell.
Special teams included
P, K, H, LS, KR and PR are chart rows. Test: every club row above shows a non-zero special-teams count that matches its live page.
Versioned against roster moves
A chart is only true until the next transaction. Test: each row carries the club's own printed date where it has one, and the capture is superseded when the transaction log shows a move.
