This page records the market's number for the same game, market and moment, in a separate keyed store, so the same line can be re-read later without guessing what the market looked like. 02 · Origination order

Side first, then the total, then the moneyline

The order is not a preference. Each market is priced off a different error process, and the weakest-supported market is originated last so it inherits a spread that has already been checked rather than standing in for one.

#MarketOrderWhy this positionStateOfficial sourceMarket source
1Spread / side1Originated first: the spread is the market with the deepest public data (every final score), the smallest variance per game, and the only market whose error this desk can measure against 105 out-of-sample games. It is the market a team-form model is best equipped to price.originatednfl.com schedule ↗market line ↗
2Total (over/under)2Originated second: the total depends on pace and on both scoring rates, which the same model already estimates, but it is priced off a different error process - the margin-vs-total correlation is negative, so a side edge says nothing about the total.originatednfl.com schedule ↗market line ↗
3Moneyline3Originated last: the moneyline is a monotone transform of the spread only if you also model the push/tie mass and the vig. It inherits every spread error and adds conversion error, so it is the least defensible of the three until the spread gate has actually been passed.originatednfl.com schedule ↗market line ↗
All three markets are originated from the same team-rate model, so the order is about evidence, not machinery. The side carries the only out-of-sample error this desk can measure; the moneyline carries every spread error plus a conversion error on top of it.
03 · Fair, market, difference

Three columns, never blended

Fair is ours. Market is theirs. Difference is the subtraction and nothing else. Keeping them apart is what makes it possible to tell a model that disagrees with the market from a model that has simply been read off the market.
