A backtest is only as good as its results file

ROI, closing-line value and any honest hit rate need settled outcomes joined to the exact line that was originated. This page is that join. A game that has not been played is marked pending with every outcome column empty, because a pending game scored as a win is the single easiest way to manufacture a track record.

Rule 1

Nothing is graded without a final

A row becomes final only when the game appears in the verified result set, which is built from NFL.com game pages and proved against the official standings.

Rule 2

Accuracy, not profit

The grade says whether our number landed closer to the truth than the market's. It does not say we won a bet, because this desk publishes no picks and stakes nothing.

Rule 3

The feed is the input

When a strategy is finally eligible for reward, the ROI it reports has to be recomputable from this table and no other.

Fair margin is home minus away; the market column is the published home line, which carries a negative number for the favourite. Accuracy compares the absolute error of each against the actual margin, so the two conventions cannot flatter either side. A row is graded only when the game exists in the verified result set. Until then every result column is blank and the row says pending - a pending game is never scored as a win. 'Closer' means our line landed nearer the truth than the market line did; it is a statement about accuracy, not about money, because this desk publishes no picks and stakes nothing.
What this feed makes possible

Compute on it, do not assume it

Measures are defined now; the numbers arrive when games are final.

Hit rate - share of final rows graded closer than the market. Denominator is finals only.
Closing-line value - our fair number minus the closing market number, once a closing snapshot exists. It requires the snapshot store, which is why that store was built first.
ROI - flat 1-unit stakes at a declared price on the graded call, reported with its sample size and never as a percentage of an unknown bankroll.
Backtest - any retrospective score must run on this same join, with the pending rule applied, or it is not measuring the strategy this site publishes.
