Correlation Reference

The brief asks for correlation values. This page enumerates every pair that matters and says exactly how each value will be estimated. It publishes no numbers, because no correlation has been estimated yet.

Every value cell on this page is blank on purpose. Sixteen pairs are listed; zero values are estimated. Inventing a plausible-looking correlation would be the most damaging thing this project could do: parlay and same-game-combination prices are driven entirely by it, so a wrong correlation produces a confidently wrong price. A blank cell is honest. A guessed cell is dangerous.

The register

Estimation protocol

  1. Source the data first. Correlation cannot be estimated from standings or injury reports. It needs play-by-play or per-game player statistics plus price history (Q-09, Q-11).
  2. Fix the window before looking. Choose the estimation window (Q-15), then estimate. Choosing the window after seeing the result is how a number gets tuned to a story.
  3. Report n, the estimator and the standard error next to every value. A correlation without a sample size is decoration.
  4. Estimate both pooled and per-season and report the disagreement as the G5 stability metric.
  5. Never extrapolate across contexts. A correlation estimated on ordinary weeks does not apply to weeks with playoff-seeding dependencies (C-08), and a cross-game correlation assumed to be zero should be tested against zero rather than assumed (C-07).
  6. Treat mechanical relationships as structural, not free. A receiver's yards are a component of his quarterback's passing yards (C-03). That is arithmetic, not a parameter to fit.

The one correlation most people forget

C-14: the correlation between your own strategies. Two strategies that fire on the same underlying signal are not independent, even across different games. Estimate the correlation matrix of per-week strategy returns directly rather than inferring it from leg-level correlations. A portfolio that looks diversified on paper can be a single concentrated bet once this is measured — and it is exactly the kind of hidden concentration that makes a "diversified" set of strategies blow up together.
