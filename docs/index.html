X4 is an NFL signal and strategy research console. It exists to originate independent NFL prices, turn them into strategies, and admit a strategy to the leaderboard only after it passes validation gates designed to strip out luck. Every number on this site is either traced to an official primary source or left blank and flagged.

Two sites in one repository. This is the X4 Console, built by a parallel session, and it is published alongside the main NFL Decision Desk. The two builds were produced independently from the same empty repository on the same day and disagree about presentation, not about facts: both independently concluded that the NFL publishes no betting lines and that no official source labels depth-chart strings. The reconciliation is logged in COORDINATION.md.
Read this first. No strategy on this site has been backtested. No correlation value has been estimated. No bet has been placed. There is no odds data, no play-by-play data and no historical dataset in this repository. Everything in the Strategy Catalog is a hypothesis with an entry rule, not a result. See Flagged for Review for the full list of gaps.

Two gaps block most of the brief

The brief asks for depth-based signals (2nd/3rd/4th string) and for originated lines. Both run into the same wall: there is no official primary source for either.

Gap 1 · Depth / "string"
No official source
NFL.com returns 404 for team depth-chart pages. Club sites publish ordered charts but never label 1st/2nd/3rd/4th string. F-03
Gap 2 · Betting prices
No official source
The league does not publish odds. Every odds-derived number — CLV, correlation, edge — is unverifiable against a primary source. F-02

Both gaps are recorded with sources on the Flagged for Review page. Neither blocks this site; both block the strategy work.

How to read any table on this site

  1. Status column. verified means the value was read off an official primary source during this session and the URL is recorded. design means it is this project's own engineering proposal. secondary means it rests on a media or aggregator source. unverified means we do not know.
  2. Blank cells. A blank cell renders as — unverified —. It is never filled in with an estimate, an interpolation or a plausible guess.
  3. Source column. Every row links out. If a row's source is weak, the status column says so.
  4. Sorting and filtering. Click any column header to sort. Use the search box and dropdowns to filter.
